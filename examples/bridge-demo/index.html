What is Hedgents Stablecoin Rail?

Hedgents Stablecoin Rail is a non-custodial TypeScript SDK that lets Solana applications accept stablecoins from other chains through existing transport providers. It combines provider-neutral quotes, resumable transfer state, unsigned wallet requests, and Solana settlement verification behind one interface.

It is free to use under Apache-2.0 and does not require a Hedgents account, token, bridge, validator network, or custodial wallet.

  • 7 published npm packages
  • 226 deterministic tests
  • 1 public mainnet transfer proof
  • 0 runtime dependencies in the core

How does stablecoin funding into Solana work?

  1. The application describes the source asset, Solana recipient, and minimum outcome.
  2. Provider plugins return comparable quotes and unsigned wallet requests.
  3. The rail tracks the transfer, survives reloads, and verifies settlement on Solana.

Why not integrate a bridge directly?

A bridge moves tokens. A Solana application still has to compare outcomes, protect API keys, validate assets, handle wallet requests, recover interrupted transfers, and prove what arrived. Stablecoin Rail turns those repeated integration problems into a public plugin contract while leaving transport to established providers.

Stablecoin Rail FAQ

Is Stablecoin Rail a bridge?

No. It is an application layer over established transports such as Circle CCTP, LayerZero, and Mayan. It does not run a validator network, issue a token, or custody funds.

What does it provide to Solana developers?

Comparable quotes, route validation, unsigned wallet requests, resumable state, status tracking, and settlement verification through one TypeScript interface.

Which routes are proven today?

Ethereum USDC to Solana USDC through Circle CCTP V2 has a published mainnet proof. Other routes in the alpha remain unproven or gated and are documented as such.

Is it ready for production?

No. The project is an alpha and has not had an independent security review. Read the public status and evidence before testing with real funds.
